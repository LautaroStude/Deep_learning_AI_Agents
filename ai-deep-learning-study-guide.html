Deep Learning to AI Agents
Study Guide

A phased learning path from neural network fundamentals to building autonomous AI agents and multi-agent systems.

Phase 1 Foundations of Deep Learning Weeks 1–4 Weeks 1–8

Build rock-solid intuitions for how neural networks learn. Focus on the math (just enough), backpropagation, and getting comfortable with PyTorch.

Deep Learning Specialization
FREE AUDITVIDEO
5-course sequence on Coursera. Start here for a structured walkthrough of neural nets, optimization, CNNs, RNNs, and sequence models. Andrew Ng's explanations of the intuition behind gradient descent and regularization are unmatched.
Andrew Ng — DeepLearning.AI / Coursera
Practical Deep Learning for Coders
FREEHANDS-ON
Jeremy Howard's legendary top-down course. You'll train real models from lesson 1, then peel back the layers. The perfect complement to Ng's theory-first approach. Uses PyTorch & the fastai library.
Jeremy Howard — fast.ai
Neural Networks: Zero to Hero
FREEYOUTUBE
Andrej Karpathy builds everything from scratch in Python — micrograd, makemore (bigrams → MLPs → WaveNet), then a full GPT. The best "learn by building" resource on the internet. 8 lectures, code along with every one.
Andrej Karpathy
3Blue1Brown — Neural Networks
FREEVISUAL
Grant Sanderson's animated explanations of backpropagation and gradient descent. Watch these whenever a concept from the other courses feels fuzzy — the visualizations make everything click.
Grant Sanderson — 3Blue1Brown
Milestone Project

Train an image classifier on a custom dataset (e.g., dog breeds or plant diseases) using PyTorch. Deploy it as a simple web app with Gradio or Streamlit. You should be able to explain backpropagation on a whiteboard.

Phase 2 LLMs, Transformers & NLP Weeks 5–8 Weeks 9–18

Understand the transformer architecture that powers everything in modern AI — from GPT to diffusion models. Learn how LLMs are trained, fine-tuned, and deployed.

Karpathy: Let's Build GPT
FREEBUILD
Lectures 7 & 8 from Zero to Hero. Build a GPT from scratch following "Attention is All You Need," then build the BPE tokenizer. This is where everything from Phase 1 pays off.
Andrej Karpathy
Stanford CS224N — NLP with Deep Learning
FREELECTURES
Stanford's flagship NLP course. Full lecture videos, slides, and assignments available free online. Covers word vectors, dependency parsing, transformers, pretraining, and more. Academic rigor meets real-world applications.
Chris Manning — Stanford
Karpathy: Deep Dive into LLMs
FREEYOUTUBE
A 3.5-hour deep dive into how LLMs like ChatGPT actually work under the hood — pretraining, RLHF, tokenization, sampling, and the full training pipeline. Essential context before you start building with LLM APIs.
Andrej Karpathy
Hugging Face NLP Course
FREEINTERACTIVE
Learn how to use the Transformers library, tokenizers, fine-tuning, and the Hugging Face ecosystem. This is where you go from "understanding transformers" to "actually using them in production."
Hugging Face Team
Prompt Engineering for Developers
FREESHORT
DeepLearning.AI short course on working effectively with LLM APIs — system prompts, few-shot patterns, chain-of-thought, and structured outputs. A must before moving to agents.
Isa Fulford & Andrew Ng — OpenAI / DeepLearning.AI
Milestone Project

Fine-tune a small language model (e.g., GPT-2 or a 7B open-source model) on a custom dataset using Hugging Face. Build a RAG (Retrieval-Augmented Generation) chatbot that can answer questions about a set of PDFs.

Phase 3 AI Agents — Single Agent Systems Weeks 9–12 Weeks 19–28

Move from calling LLM APIs to building autonomous agents that use tools, maintain memory, make decisions, and take actions in the real world.

FREEHANDS-ON
Build an agent from scratch in Python, then rebuild it properly using LangGraph's stateful graph-based orchestration. Covers tool use, memory, branching, and human-in-the-loop patterns.
Harrison Chase & Rotem Weiss — LangChain / DeepLearning.AI
Functions, Tools & Agents with LangChain
FREESHORT
Learn how to give LLMs the ability to call functions, use tools (search, code execution, APIs), and act as autonomous agents. The bridge from "chatbot" to "agent."
Harrison Chase — LangChain / DeepLearning.AI
LangChain Academy
FREECOURSES
Official LangChain learning platform with structured courses on LangGraph, tool use, RAG, and agent architectures. Updated regularly with the latest patterns and best practices for building production agents.
LangChain Team

Build a research agent that can search the web, read documents, and produce a structured report. It should plan its own steps, use tools, and handle errors gracefully. Use LangGraph or the OpenAI Agents SDK.

Phase 4 Multi-Agent Systems & Frameworks Weeks 13–18 Weeks 29–38

Scale from a single agent to teams of specialized agents that collaborate, delegate, and solve complex problems together.

Phase 5 OpenClaw, AutoResearch & The Frontier Weeks 19–24 Weeks 39–48

Explore the cutting edge — open-source agentic frameworks running locally, autonomous research pipelines, and the tools shaping the future of AI engineering.

OpenClaw — Open-Source AI Agent Framework
FREE / OSSLOCAL
The most-starred open-source project on GitHub (280K+ stars). A personal AI agent that runs locally, remembers context across sessions, and integrates via Signal/Telegram/Discord. Study the architecture, build custom "skills" for ClawHub, and understand the MCP (Model Context Protocol) integration. Bring your own API key — no subscription needed.
Peter Steinberger / Community
AutoResearch & AutoResearchClaw
FREE / OSSRESEARCH
Andrej Karpathy's AutoResearch is a 630-line Python framework that lets AI agents run hundreds of ML experiments autonomously on a single GPU. AutoResearchClaw integrates it with OpenClaw — "Chat an Idea. Get a Paper." Study the pipeline, run it, then extend it with your own research ideas.
Andrej Karpathy / aiming-lab
Anthropic MCP & Claude Agent SDK
FREE DOCSPROTOCOL
Model Context Protocol (MCP) is becoming the standard for how agents connect to external tools and data. Study the spec, build MCP servers, and understand how Claude's agent architecture works. This is the infrastructure layer that makes OpenClaw and similar tools possible.
Anthropic
O'Reilly: The Next Phase of AI Agents
FREEANALYSIS
O'Reilly's analysis of what OpenClaw reveals about the future of AI agents — proximity (running locally), creativity (skills marketplace), and extensibility (open protocols). Read this to understand where the field is heading.
O'Reilly Radar
Milestone Project

Build and publish a custom OpenClaw skill that does something useful — a research assistant, a code reviewer, a data analyst. Deploy it via ClawHub. Alternatively, set up an AutoResearch pipeline for a topic you're interested in and run autonomous experiments.

Study Tips for Success

Code everything yourself

Don't just watch lectures. Type out every line of code, break things, fix them. Karpathy's courses are designed for this — pause, code, then continue.

Build a portfolio on GitHub

Every milestone project should go on GitHub with a solid README. By Phase 5, you'll have 5+ real projects that demonstrate a complete journey from fundamentals to frontier.

Read papers early

Start reading "Attention is All You Need" during Phase 2. Use Yannic Kilcher and Umar Jamil's YouTube channels for paper walkthroughs. Reading papers is a skill — start building it now.

Join communities

fast.ai forums, LangChain Discord, Hugging Face community, r/MachineLearning, and r/LocalLLaMA. Ask questions, share projects, and learn from what others are building.

Use the "two-pass" method

Watch Ng or fast.ai first for intuition. Then watch Karpathy to build it from scratch. The concepts stick when you see them from two different angles.

Stay current

Follow Karpathy, Jim Fan, Yann LeCun, and Harrison Chase on X/Twitter. Subscribe to "The Batch" (DeepLearning.AI newsletter). The field moves fast — 15 min/day of reading keeps you in the loop.
